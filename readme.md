# 🧪 Postman API Testing - Chaining Project

This project demonstrates **API Request Chaining** using Postman.  
Each request is dependent on the response of the previous one, utilizing environment variables.

## 📌 Collection Includes:
- ✅ `POST` Create user
- 📥 `GET` Retrieve user details
- ✏️ `PUT` Update user details
- ❌ `DELETE` Remove user

## 🧠 Concepts Used:
- Environment Variables
- Pre-request Script
- Test Script Assertions
- JSON Parsing
- Response Chaining

## 🚀 How to Run
1. Import the collection file: `GoRestapicollection.postman_collection.json`
2. Add your Bearer Token to the environment or authorization
3. Run each request step-by-step OR use **Collection Runner**
